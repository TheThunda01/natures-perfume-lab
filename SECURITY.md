# Security

This project processes bundled public snapshots. Its supported workflow is the fixed case described in the [practical-use guide](docs/practical-use.md); it is not a service for receiving arbitrary uploaded files.

If you find a suspected vulnerability, report it privately to the maintainer. If the repository host provides private vulnerability reporting, use that route. Otherwise, request a private contact channel without publishing the exploit details, credentials, or private records. Do not assume an upstream data provider or library maintains this project.

Include the affected commit, environment, observed behavior, potential impact, and a minimal synthetic reproducer. For ordinary documentation or calculation bugs that do not expose sensitive information, use the project's normal contribution process.
