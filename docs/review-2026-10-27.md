# Editorial and verification record — 27 October 2026

## Scope

This record describes the initial review of Nature's perfume lab. The project connects a selected chemical pathway example to enzyme sequences and one experimental structure. It does not report new wet-lab or sensory work, train a machine-learning model, or predict odor.

## Writing and evidence checks

The documentation follows the supplied *Writing in the Sciences* principles: state the main point first, name the actor when it helps, use precise verbs, and keep each paragraph focused. Scientific limits remain beside the claims they qualify. Technical terms are defined in context and in the glossary.

The README and guides distinguish source annotations, graph calculations, curated atom correspondence, sequence alignment, and structural observations. The literature review and reference audit record which sources were accessed and what they support. AI assistance is disclosed; it is not treated as a source of biological evidence.

- All 33 tests passed: 20 verifier tests, 10 chemistry tests, and 3 output-protection tests. The output checks include refusing to replace an unrelated JavaScript file.

GitHub Actions is configured to run the analysis tests, verify the recorded bundle and explorer data, reproduce and verify a fresh bundle, and check documentation. This record reports local execution; it does not claim a hosted CI run. The browser check is a separate optional development step.

## Remaining limits

A passing computational check does not validate a biological mechanism or a sensory claim. The selected cases are not a representative enzyme survey. Source access and interpretation limits remain in the reference audit. Browser checks cover the recorded Chromium setup, not all browsers or assistive technologies, and do not replace evaluation with readers. Windows and macOS execution were not tested in this review.

## Publication validation addendum — 27 October 2026

An independent Windows run checked this release in a fresh Python 3.12 environment with the pinned dependencies. The initial reproduction exposed a platform-specific SVG export issue: Windows text output converted line endings to CRLF while the copy embedded in the analysis JSON retained LF. Both SVG exporters now write explicit LF line endings. A regression test compares the generated SVG bytes with the embedded value; the verifier's exact comparison remains unchanged.

After that correction:

- Dependency consistency passed (`python -m pip check`).
- The full suite ran 34 tests: 31 passed and three symbolic-link tests were skipped because this Windows environment cannot create symbolic links.
- The independent verifier accepted the recorded results and explorer payload, and a fresh reproduction in a separate output directory. Each verification checked ten artifacts, two enzymes, three molecular graphs, and two balanced reactions.
- The portfolio documentation checker passed structure, source-audit, and local-link checks.
- The original source snapshots, recorded result bundle, and explorer assets were preserved. This run did not repeat the optional browser smoke test or validate biological or sensory claims.

This addendum extends the earlier local review with Windows execution evidence. Hosted workflow outcomes are available in the repository's [GitHub Actions history](https://github.com/TheThunda01/natures-perfume-lab/actions); macOS remains untested.
